# AGENTS.md — постоянные правила для работы над support-chat

## Общение
- **Всегда общаться полностью на русском языке** (ответы, планы, комментарии, коммит-сообщения по возможности). Это жёсткое требование пользователя.

## Работа с репозиторием
- Никаких переделок и рефакторинга без явного запроса — сначала уточнить.
- Не публиковать секреты (пароли, токены, ключи, содержимое `.env`) в коде, логах или коммитах.
- Деплоить изменения на прод (VPS), а не «крутить только на локалке». Прод: `https://sct.chat`.

## Деплой (кратко)
- Сервер: `ssh -i C:\Users\LEGION\.ssh\support_chat_deploy root@31.59.125.234`
- Обновление: `cd /root/support-chat && git pull --ff-only origin main && docker compose --env-file deploy/.env -f docker-compose.prod.yml up -d --build`
- После пересборки — при необходимости `chown -R 1000:1000` на volume `support-chat_uploads`.
- Подробности — в `README.deploy.md`.
