# План профессионального рефакторинга фронтенда на React + TypeScript (только фронтенд)

## Цель
Полностью переписать фронтенд (operator + admin панели) на React 18+ с TypeScript, используя современную модульную архитектуру, красивый UI на базе MUI (Material-UI). **Бэкенд остаётся без изменений** - работаем с текущим API.

## Выбор технологий (обоснованный)

### 1. Фреймворк: React 18 + TypeScript
- Наиболее популярный, огромное сообщество
- Компонентный подход идеален для SPA
- Отличная TypeScript поддержка
- Много готовых библиотек

### 2. UI библиотека: MUI v5 (Material-UI)
- Полный набор компонентов
- Профессиональный дизайн
- WCAG 2.1 совместимость

### 3. State Management
- **Zustand** - глобальное состояние (теги, operators, WS)
- **React Query** - серверное состояние (chats, archive, stats)
- **Context API** - для auth

### 4. Другие инструменты
- Vite (build)
- Axios (HTTP)
- React Hook Form + Zod (валидация)
- React Router v6 (маршрутизация)
- Vitest + RTL (тесты)

## План миграции (инкрементально)

### Подход: Параллельное держание старого и нового фронтенда. Постепенная замена страниц.

### ФАЗА 0: Инициализация (2 часа)

**0.1 Создание проекта Vite + React + TS**
```bash
# В папке frontend (создаем новый проект, не удаляя старый)
npm create vite@latest frontend-react -- --template react-ts
cd frontend-react
```

**0.2 Установка зависимостей**
```bash
npm install @mui/material @mui/icons-material @emotion/react @emotion/styled
npm install react-router-dom zustand @tanstack/react-query axios
npm install react-hook-form zod @hookform/resolvers
npm install -D vitest @testing-library/react jsdom eslint prettier
```

**0.3 Структура папок**
```
src/
├── components/
│   ├── ui/           # Button, Input, Card, Badge, Modal, Confirm...
│   ├── layout/       # Layout, Sidebar, Header
│   ├── chat/         # ChatList, ChatItem, MessageBubble, InputArea
│   ├── archive/      # ArchiveFilters, ArchiveList, TagFilter
│   └── common/       # EmptyState, Spinner, Toast
├── pages/
│   ├── Login.tsx
│   ├── Register.tsx
│   ├── operator/
│   │   ├── OperatorDashboard.tsx
│   │   ├── ChatView.tsx
│   │   ├── ArchiveView.tsx
│   │   └── StatsView.tsx
│   └── admin/
│       ├── Operators.tsx
│       ├── Invites.tsx
│       ├── Tags.tsx
│       ├── Settings.tsx
│       ├── Audit.tsx
│       └── Stats.tsx
├── hooks/            # useWebSocket, useAuth, useChats, useArchive, useTags
├── services/         # api.ts (axios), ws.ts
├── stores/           # Zustand (chatStore, archiveStore, tagStore, uiStore)
├── utils/            # formatters, validators (Zod schemas)
├── types/            # TypeScript типы
├── theme/            # MUI theme (настройка под бренд)
├── router/           # routes, ProtectedRoute
├── App.tsx
└── main.tsx
```

**0.4 Настройка Vite (vite.config.ts)**
- Прокси `/api` → `http://localhost:3000`
- Алиасы: `@/` → `src/`

**0.5 MUI Theme (theme/index.ts)**
```typescript
export const theme = createTheme({
  palette: { primary: { main: '#007bff' }, background: { default: '#f5f7f9' } },
  typography: { fontFamily: 'Inter, sans-serif' },
});
```

### ФАЗА 1: Базовая инфраструктура (1-2 дня)

**1.1 UI Kit (MUI theme override)**
- Button, Input, Textarea, Select
- Card, Badge, Avatar
- Modal, ConfirmDialog, Toast
- Table, EmptyState, LoadingSpinner

**1.2 Layout**
- `OperatorLayout` (sidebar + main + right panel)
- `AdminLayout` (sidebar + main)
- `ProtectedRoute` (проверка токена)

**1.3 Хуки**
- `useAuth()` - токен, роль, логин/логаут
- `useWebSocket()` - подключение, авто-реконнект, подписка
- `useChats()` - загрузка чатов (React Query)
- `useArchive()` - загрузка архива с фильтрами
- `useTags()` - загрузка и управление тегами

**1.4 Stores (Zustand)**
- `useChatStore` - открытые чаты, активный чат, tabs
- `useArchiveStore` - архив, фильтры (status, from, to, selectedTags)
- `useTagStore` - все теги, загрузка
- `useUIStore` - модалы, уведомления, loading

**1.5 Сервисы**
- `api.ts` - axios instance с interceptor (токен)
- `ws.ts` - WebSocket singleton менеджер
- `endpoints.ts` - функции для вызова API

**Компоненты:**
- `ArchiveFilters` (уже есть из vanilla, адаптируем под React)

- `ArchiveList` - список архивных чатов (виртуализация при большом объеме)
- `ArchiveChat` - просмотр (read-only)

**Логика:**
- Авто-apply фильтров при изменении (debounce 300ms)
- Выбор чата → загрузка сообщений

#### 2.4 Stats View (4 часа)

## Важные примечания

### Работа с текущим API (бэкенд без изменений)
- Используем существующие эндпоинты (`/chats`, `/messages/:id`, `/admin/*`)
- Поля `client_name`, `client_device`, `client_region` уже есть в SELECT (atis) - проверить что приходят
- JWT без expiration (frontend ранее добавил проверку exp для admin, для operator тоже нужно)
- WebSocket аутентификация через `auth` message

### Безопасность (фронтенд)
- React生态чески экранирует XSS (используем dangerouslySetInnerHTML только если нужно)
- Валидация всех форм (Zod)
- Токен в localStorage (пока оставляем)
