# План: Исправление бага с архивом — список чатов пропадает при длинном чате

## Проблема

Когда открываешь длинный чат в архиве, `#archive-chat-area` растягивается на всю высоту страницы, и список `#archive-list` исчезает из видимости. Невозможно переключиться на другой чат из архива.

## Корневая причина

В CSS `operator.html` строка 174:
```css
#archive-view { flex-direction: column; }
```

Из-за `flex-direction: column` список архива и область чата располагаются вертикально (друг под другом), а не горизонтально (рядом). При длинном чате `#archive-chat-area` занимает всё пространство и выталкивает список за пределы видимости.

Также `#archive-list` имеет `flex: 1` (строка 175), что заставляет его растягиваться в column-направлении, вместо фиксированной ширины.

## Исправление

### 1. Изменить `flex-direction` для `#archive-view` на `row`

Строка 174:
```css
/* Было: */
#archive-view { flex-direction: column; }
/* Стало: */
#archive-view { flex-direction: row; }
```

### 2. Убрать `flex: 1` у `#archive-list`, добавить `flex-shrink: 0`

Строка 175:
```css
/* Было: */
#archive-list { flex: 1; overflow-y: auto; background: #fff; }
/* Стало: */
#archive-list { width: 300px; flex-shrink: 0; overflow-y: auto; background: #fff; }
```

Ширина `300px` уже задана inline-стилем в HTML (строка 338), но лучше продублировать в CSS для надёжности.

### 3. Убрать inline-стиль `width:300px` из HTML (опционально)

Строка 338 — убрать `style="width:300px;border-right:1px solid var(--border);overflow-y:auto;"` поскольку эти стили теперь в CSS. Но `border-right` и `overflow-y` нужно перенести в CSS.

Итоговый CSS для `#archive-list`:
```css
#archive-list { width: 300px; flex-shrink: 0; overflow-y: auto; background: #fff; border-right: 1px solid var(--border); }
```

```

```
