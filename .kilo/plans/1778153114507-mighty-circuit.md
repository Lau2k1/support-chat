# План: удаление vanilla-фронтенда + исправление бага админки

## 1. Исправить баг "No token provided" при переходе в админку

**Причина:** В `TopBar.tsx:113` кнопка «Админ» использует `href="/admin"`, что вызывает **полную перезагрузку страницы**. Браузер делает HTTP-запрос GET `/admin` → Vite проксирует на бэкенд → бэкенд обрабатывает `/admin` как API-маршрут → authMiddleware возвращает 401 "No token provided".

**Исправление:** Заменить `href="/admin"` на React Router навигацию:
```tsx
// Было:
<IconButton href="/admin" ...>

// Станет:
import { useNavigate } from 'react-router-dom';
const navigate = useNavigate();
<IconButton onClick={() => navigate('/admin')} ...>
```

**Файлы:** `frontend-react/src/components/layout/TopBar.tsx`

## 2. Переключить бэкенд на раздачу React-фронтенда

**Сейчас:** `server.ts:27-28` раздаёт `../../frontend` (vanilla HTML).
**Надо:** Раздавать `../../frontend-react/dist` (собранный React).

**Изменения в `backend/src/server.ts`:**
```ts
// Было:
const frontendPath = path.join(__dirname, '../../frontend');
app.use(express.static(frontendPath));

// Станет:
const frontendPath = path.join(__dirname, '../../frontend-react/dist');
app.use(express.static(frontendPath));
```

**Добавить SPA fallback** (чтобы React Router работал при прямых URL типа `/login`, `/admin`):
```ts
// После всех API-роутов, перед server.listen:
app.get('*', (_req, res) => {
  res.sendFile(path.join(frontendPath, 'index.html'));
});
```

## 4. Обновить Vite proxy

В `vite.config.ts` прокси `/admin` конфликтует с React Router маршрутом `/admin`. Vite проксирует `/admin/*` на бэкенд, а React Router тоже обрабатывает `/admin`. Нужно изменить прокси, чтобы `/admin` проксировался **только** для API-путей (например, `/admin/operators`, `/admin/tags` и т.д.), а не для корневого `/admin`.

Решение: уточнить прокси-правила — проксировать `/admin/` (со слешем), а не `/admin`. Либо ещё лучше — проксировать по конкретным путям:

```ts
proxy: {
  '/login': 'http://localhost:3000',
  '/register': 'http://localhost:3000',
  '/chats': 'http://localhost:3000',
  '/messages': 'http://localhost:3000',
  '/chat-status': 'http://localhost:3000',
  '/upload': 'http://localhost:3000',
  '/rate': 'http://localhost:3000',
  '/stats': 'http://localhost:3000',
  '/canned-responses': 'http://localhost:3000',
  '/admin/operators': 'http://localhost:3000',
  '/admin/invite-codes': 'http://localhost:3000',
  '/admin/operator-stats': 'http://localhost:3000',
  '/admin/chats': 'http://localhost:3000',
  '/admin/tags': 'http://localhost:3000',

}
```
