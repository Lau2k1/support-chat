# План: Фикс read_at + Улучшение UI виджета

## 1. Баг: column "read_at" does not exist

**Причина:** Схема `init.sql` содержит `read_at TIMESTAMP NULL` в таблице `messages`, но миграция не была применена к существующей БД. `CREATE TABLE IF NOT EXISTS` не добавляет колонку, если таблица уже существует. Нужен `ALTER TABLE ADD COLUMN IF NOT EXISTS`.

**Фикс:** Добавить в `backend/src/db/schema/init.sql` после CREATE TABLE messages:

```sql
ALTER TABLE messages ADD COLUMN IF NOT EXISTS read_at TIMESTAMP NULL;
```

И убедиться, что `init.sql` выполняется при старте сервера. Проверить, где вызывается схема.

**Дополнительно:** В `handler.ts:145` — `messageRead` кейс делает UPDATE read_at. Если колонки нет — ошибка. Нужно также проверить, что при запуске сервера init.sql выполняется.

## 2. Улучшение UI виджета

Текущий виджет выглядит как базовый чат из 2010-х. Нужно сделать его современным, как у Intercom/Crisp/Drift.

### 2a. Экран приветствия

**Сейчас:** При открытии виджета без чата — текст "Начните диалог". Скучно.

**Стало:** Красивый приветственный экран:
- Иконка чата / аватар оператора
- Заголовок "Чем можем помочь?"
- Подзаголовок "Обычно отвечаем в течение нескольких минут"
- Кнопка "Начать чат" (отправляет init_chat)

Это даёт пользователю понимание, что он общается с живым человеком, а не ботом.

### 2b. Временные метки сообщений

**Сейчас:** Сообщения не имеют времени.

**Стало:** Каждое сообщение показывает время (HH:MM) мелким шрифтом под пузырём. Добавить `formatWidgetTime` в виджет.

### 2c. Имя оператора в сообщениях

**Сейчас:** Сообщения оператора не показывают имя.

**Стало:** Над первым сообщением оператора в серии — имя оператора мелким текстом.

### 2d. Улучшенный хедер

**Сейчас:** Синий хедер с текстом "Поддержка".

**Стало:**
- Градиентный хедер (от #4f46e5 до #7c3aed)
- Иконка чата + "Поддержка"
- Статус-индикатор (зелёная точка + "Онлайн" / серая + "Оффлайн")
- Кнопка свернуть (—

### 2e. Улучшенная кнопка "Поддержка"

**Сейчас:** Плоская синяя кнопка.

**Стало:**
- Круглая кнопка с градиентом (как у Intercom)
- Иконка чата SVG вместо эмодзи
- Пульсирующая анимация при непрочитанных
- Тень и hover-эффект

### 2f. Улучшенный инпут

**Сейчас:** Простой input с кнопкой ">".

**Стало:**
- Текстареа (textarea) — поддерживает многострочный ввод
- Shift+Enter — новая строка, Enter — отправка
- Кнопка отправки — SVG иконка стрелки
- Автоматическое увеличение высоты textarea

### 2g. Разделитель дат

**Сейчас:** Нет разделения по дням.

**Стало:** Если между сообщениями более 5 минут — показать временную метку. Если сообщения в разные дни — показать разделитель "Сегодня", "Вчера", или дату.

### 2h. Улучшенный rating

**Сейчас:** Звёзды на сером фоне.

**Стало:**
- Белая карточка с тенью
- Иконка "Спасибо" 
- Большие звёзды с анимацией при наведении
- После оценки — анимация "Спасибо!" с чекмарком

### 2i. Плавные переходы

- Открытие/закрытие — уже есть анимация, оставить
- Появление сообщений — fade-in + slide-up
- Typing indicator — мягкая пульсация
